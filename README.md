# Paradise Nursery

Paradise Nursery is an online plant shop shopping cart application built with React and Redux Toolkit.

## Features
- Landing page with a "Get Started" button
- Browse houseplants by category with image, name and price
- Add plants to the cart and manage quantities
- View the total cost of each plant and of the whole cart

## Tech stack
React, Vite, Redux Toolkit, react-redux
